# Lovely-Lovely

## Características
* **Género:** Romance, Drama
* **Idioma(s):** Español, futuro script en Ingles
* **Clasificación:** +16

## Controles (Estándar de Ren'Py / PC)
* **Clic izquierdo / Enter / Espacio:** Avanzar texto y confirmar selección.
* **Clic derecho / Esc:** Abrir o cerrar el menú del juego.
* **Rueda del ratón hacia arriba:** Ver el historial de diálogos.
* **Ctrl:** Avanzar rápido (Skip) los textos ya leídos.
* **Tecla H:** Ocultar la interfaz (ideal para tomar capturas de pantalla).
* **Tecla F:** Pantalla completa.
